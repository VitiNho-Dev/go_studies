# Estudos em Go — Tutoriais oficiais

Resumo
-----
Este repositório documenta o progresso dos estudos baseados nos tutoriais oficiais da linguagem Go. Contém exemplos, exercícios e pequenos projetos que acompanham os conceitos apresentados na [documentação oficial](https://go.dev/doc/).

Conteúdo
--------
- Exemplos e projetos exploratórios dentro da pasta [tutorials/](tutorials/).
  - Ex.: [tutorials/gowiki/wiki.go](tutorials/gowiki/wiki.go), [tutorials/fuzz/main.go](tutorials/fuzz/main.go)

Competências adquiridas
-----------------------
- Sintaxe básica: declarações, tipos, constantes e inferência de tipos.
- Controle de fluxo: if, for, switch e uso idiomático de condicionais.
- Funções: múltiplos retornos, closures e funções anônimas.
- Structs e pointers: definição, inicialização e passagem por referência.
- Métodos e interfaces: implementação de métodos e uso de interfaces simples.
- Pacotes e módulos: organização com go modules e importações.
- Tratamento de erros: padrão de retorno de erro, wrapping e checagem.
- Concorrência básica: goroutines, canais e padrões simples de sincronização.
- Biblioteca padrão: uso de fmt, io, os, net/http, encoding/json, entre outras.
- Ferramentas: go fmt, go vet, go test.

Resultados observáveis
----------------------
- Capacidade de ler e adaptar exemplos da documentação oficial.
- Pequenos programas funcionais (servidores HTTP simples, manipulação de arquivos/JSON, exemplos de concorrência).
- Testes básicos para funções críticas usando package testing.

Pontos fortes
-------------
- Boa compreensão dos fundamentos do Go.
- Familiaridade com ciclo de desenvolvimento: escrever, formatar e testar.
- Experimentos práticos com tutoriais oficiais reproduzidos no repositório.
