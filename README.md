# Go Studies

Repositório dedicado aos meus estudos em Go.

Aqui concentro exercícios, experimentos e pequenos projetos desenvolvidos a partir de:

- Documentação oficial  
- Cursos  
- Sites de exercícios  
- Desafios de programação  
- Explorações pessoais  

O foco é evoluir na escrita de código idiomático, simples e eficiente.

---

## Estrutura

```
tutorials/   -> exemplos baseados na documentação oficial
exercises/   -> exercícios diversos (sites, cursos, desafios)
projects/    -> pequenos projetos práticos
```

---

## Conceitos praticados

- Sintaxe e tipos
- Controle de fluxo
- Funções e múltiplos retornos
- Structs e ponteiros
- Métodos e interfaces
- Tratamento de erros
- Pacotes e módulos
- Concorrência (goroutines e channels)
- Testes com `testing`
- Uso da biblioteca padrão

---

## Objetivo

Consolidar fundamentos e evoluir para:

- Desenvolvimento de APIs
- Arquitetura de projetos em Go
- Concorrência avançada
- Projetos prontos para produção
